# Virtual Meter Guide

`Large_Market_Virtual_Meters.html` is the working guide for setting up the renewable-certificate
virtual meters at the AU large market electricity sites — the brief, the evidence, the step-by-step,
and a checklist of every account to create with the values to key in and the source account to link.
It also carries the tick-list for the ten NMIs that are double counting, where the old Origin account
still has to be closed at 30 Jun 26.

**Open it by double-clicking the file** (it is self-contained; no server needed). Ticks and notes are
saved in that browser — use *Save progress…* to copy them to another device or browser.

It is generated from the review workbook one folder up
(`Account_Setup_and_Data_Load_-_PM&C_LMCERTSJUL26_Setup.xlsx`) and the Jun–Aug 26 Envizi summary, so
the numbers on the page and in the workbook agree. Built 04 Sep 2026 from the 03 Sep 2026 accounts
extract.
