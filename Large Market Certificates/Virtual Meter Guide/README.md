# Virtual Meter Guide

`Large_Market_Virtual_Meters.html` is the working guide for setting up the renewable-certificate virtual
meters at the AU electricity sites under the FY26–28 renewal agreements — the brief, the evidence, and a
checklist of every account to create with the values to key in and the source account to link. It also
carries the tick-list for the 13 NMIs that are double counting, where an old account still has to be
closed off.

**Open it by double-clicking the file** (it is self-contained; no server needed). Ticks and notes are
saved in that browser — use *Save progress…* to copy them to another device or browser.

It is generated from the review workbook one folder up
(`Account_Setup_and_Data_Load_-_PM&C_LMCERTSJUL26_Setup.xlsx`) and the Jun–Aug 26 Envizi data, so the
numbers on the page and in the workbook agree. Built 04 Sep 2026 from the 03 Sep 2026 accounts extract.
